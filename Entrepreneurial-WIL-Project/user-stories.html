User Stories and Tasks

TextBook Swap SA | Entrepreneurial WIL Project

Portfolio Document 02

1. Introduction

User stories and tasks were developed to identify the needs of students who will use the TextBook Swap SA platform. They describe what users want to achieve and break the required functionality into manageable development tasks.

2. Project Goal

The goal of TextBook Swap SA is to provide a platform where university students can buy, sell and exchange second-hand textbooks at more affordable prices.

3. User Stories

US01 – User Registration

As a student, I want to create an account so that I can access the platform.

US02 – User Login

As a registered student, I want to log in so that I can access my account.

US03 – Browse Textbooks

As a student, I want to browse available textbooks so that I can find books I need.

US04 – Search for Textbooks

As a student, I want to search for specific textbooks so that I can find relevant listings quickly.

US05 – View Book Details

As a student, I want to view textbook details so that I can make an informed decision.

US06 – Create a Listing

As a student, I want to list a second-hand textbook so that other students can find it.

US07 – Manage Listings

As a seller, I want to manage my textbook listings so that I can keep them up to date.

4. Development Tasks

  • Design the registration and login interfaces.
  • Implement user authentication.
  • Create the textbook browsing interface.
  • Implement textbook search functionality.
  • Display individual textbook information.
  • Develop the sell-a-textbook form.
  • Connect listing information to the database.
  • Implement the user's listing management interface.
  • Test the features and correct identified issues.

5. Reflection: User Stories and Tasks

Working on the User Stories and Tasks for our TextBook Swap SA project helped me understand the importance of identifying user needs before developing a software application. I learned that it is important to consider the system from the user's perspective and understand what students would want to achieve when using the platform.

Our main goal was to create a platform where students could buy, sell and exchange second-hand textbooks at more affordable prices. Developing user stories helped us identify important features and user interactions, such as browsing textbooks, searching for specific books, viewing book details and creating listings.

I also learned how to structure user stories using the format "As a user, I want to..., so that..." This helped us explain the purpose of each feature and the value it would provide. Breaking these stories down into smaller tasks made it easier to understand the work involved, allocate responsibilities and track development progress.

This activity improved my understanding of Agile development because user stories and tasks help connect user requirements with the actual development process. They also allow the team to organise work, prioritise features and make improvements as the project progresses.

Overall, this activity strengthened my requirement analysis and problem-solving skills. It taught me that understanding user needs and planning features properly are important steps in developing a useful and user-friendly application. I will be able to apply these skills in future software development projects.
