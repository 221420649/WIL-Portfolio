# Textbook Swap SA — Product Backlog

## Project Overview

**Project:** Textbook Swap SA\
**Purpose:** Develop a platform where users can list, search for, and exchange or sell textbooks, with buyer–seller messaging.

This backlog is organised using the seven sprints and 54 day-based tasks listed on the project's Trello board. Task details below are based on the board titles; implementation details and acceptance criteria should be confirmed by the project team.

## Backlog Status Legend

- `[ ]` Not marked complete in this document
- `[x]` Mark complete when the team has verified the task is finished

> **Note:** The checkboxes are intentionally left unchecked because the Trello export does not consistently show the completion status of every task. Update them to match the team's current progress.

## Definition of Done

A backlog item can be marked complete when the team has verified that:

- The task's agreed deliverable has been completed.
- The relevant team member has reviewed the work.
- Required changes or defects have been addressed.
- Related project documentation has been updated, where applicable.
- The team has confirmed the task is ready to be marked complete.

## Backlog Maintenance

- Keep this file in the root directory of the GitHub repository as `Product-Backlog.md`.
- Update task checkboxes as work is verified.
- Record changes to priorities, scope, or task ownership in the team's agreed project-tracking tool.
- Use GitHub Issues or the team's project board to track detailed requirements, assignees, discussions, and acceptance criteria.
