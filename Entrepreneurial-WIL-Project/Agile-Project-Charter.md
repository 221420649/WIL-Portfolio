# Agile Project Charter

## 1. Project Overview

**Project Name:** TextBook Swap SA – Second-Hand Textbook Swap

**Module:** PRP372S – Project Presentation 3

**Institution:** Cape Peninsula University of Technology (CPUT)

**Project Type:** Entrepreneurial WIL Project

## 2. Project Purpose

TextBook Swap SA aims to help CPUT students reduce the cost of textbooks by providing a platform where students can buy and sell second-hand textbooks. The project encourages affordable access to academic resources and the reuse of learning materials.

## 3. Project Vision

To create a reliable, accessible and student-friendly platform that makes second-hand textbooks more affordable and helps students share academic resources.

## 4. Project Objectives

- Develop a functional platform for second-hand textbook listings.
- Help students find textbooks relevant to their studies.
- Support affordable buying and selling between students.
- Provide a user-friendly experience across desktop and mobile devices.
- Encourage the reuse of textbooks and reduce unnecessary spending.

## 5. Team Roles and Responsibilities

- **Litha Owethu Mazibuko – Project Facilitator/Scrum Master:** Facilitates team communication, supports Agile practices and monitors sprint progress.
- **Samkelo Mahlangu – Product Owner/Content Lead:** Prioritises the product backlog and helps ensure the platform meets user needs.
- **Coben Maistry – Frontend Developer:** Contributes to the user interface and search functionality.
- **Angelia Van der Westhuizen – UI/UX and QA Lead:** Focuses on usability, interface design and testing across devices.
- **Ongeziwe Raqa – Deployment and Documentation Lead:** Supports deployment, repository management and project documentation.

## 6. Team Values

The team values respect, communication, teamwork, transparency, constructive feedback and continuous improvement.

## 7. Communication Plan

The team uses WhatsApp for regular updates, virtual check-ins and meetings to discuss progress and challenges. GitHub supports version control and collaboration.

## 8. Project Goals

The project aims to provide a functional textbook-swapping platform with a clear interface, textbook listings and search functionality. The team also aims to test the website on different devices and improve the platform based on feedback.

## 10. Reflection

Developing the Agile Team Charter helped establish a shared understanding of the TextBook Swap SA project's purpose, vision, objectives and team responsibilities. It highlighted the importance of communication, collaboration and clear role allocation when working on an Agile project.

The charter also provided a foundation for organising project tasks and keeping the team focused on the goal of helping students access textbooks more affordably. This planning helped connect the project's intended value to the development of the working platform.
