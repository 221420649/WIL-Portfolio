# TextBook Swap SA – Live Website

## Project Overview

TextBook Swap SA is a student-focused online platform designed to help university students access affordable second-hand textbooks. The platform aims to make it easier for students to find textbooks, browse available listings and sell their own textbooks, helping reduce the cost of study materials.

## Live Application

**Website:** https://book-swap-sa.vercel.app/books/l-mu4vl3x8yaou

The live application allows users to explore the TextBook Swap SA platform and view its available functionality.

## Project Objectives

- Provide students with a convenient platform to find second-hand textbooks.
- Help students save money on academic materials.
- Allow students to list and sell textbooks.
- Create a user-friendly and accessible experience across devices.
- Encourage the reuse of textbooks among university students.

## Technologies Used

The application was developed using React, TypeScript, Vite and Firebase to support the frontend and backend functionality.

## Reflection

Developing TextBook Swap SA helped me understand how a software project moves from planning and requirements gathering to implementation. It allowed me to apply concepts related to user experience, interface design, testing and teamwork. The project also helped me appreciate the importance of developing a practical solution that addresses a real problem experienced by university students.

The live application provides evidence of the practical work completed during the Entrepreneurial WIL Project.
