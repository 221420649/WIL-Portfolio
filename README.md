# WIL Portfolio – TextBook Swap SA

## Entrepreneurial Work Integrated Learning (WIL) Project

Welcome to my Work Integrated Learning (WIL) Portfolio for the Entrepreneurial WIL Project.

This portfolio documents the planning, development, teamwork and progress of **TextBook Swap SA**, a student-focused platform designed to help university students buy, sell and exchange second-hand textbooks at affordable prices.

## Project Overview

TextBook Swap SA aims to reduce the cost of academic materials by connecting students who want to buy or sell pre-owned textbooks through an accessible online platform.
